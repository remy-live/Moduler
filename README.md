# Moduler sa carrière · le guide

Appli web pour la formation « Moduler sa carrière » (CFDT Éducation · Picardie).

On répond à quelques questions (faire une pause, travailler moins, changer de métier, quitter, santé, activité à côté) et le guide montre les dispositifs possibles : ce qu'on touche, si c'est de droit, quand demander, la démarche, un exemple chiffré et la page officielle. Quatre calculettes : temps partiel, retraite progressive, rupture conventionnelle, compte personnel de formation. « Ma fiche » garde les options choisies dans le navigateur.

- Un seul fichier : `index.html`, sans installation.
- En ligne : https://remy-live.github.io/Moduler/ (GitHub Pages, branche `main`, dossier racine).
- Règles en vigueur au 17 novembre 2026 pour les enseignants titulaires. Les pages officielles font foi.
